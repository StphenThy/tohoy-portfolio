# Stephen Tohoy's Portfolio

Open `index.html` in a browser to view the site. There's nothing to install.

The about page is what visitors see first, and each other section opens when its menu link is pressed.

## Where to edit what

| To change | Open |
| --- | --- |
| Name, status, about text, photo, social links | `js/sections/about.js` |
| Projects | `js/sections/projects.js` |
| Tech stack | `js/sections/stack.js` |
| Experience | `js/sections/experience.js` |
| Certificates | `js/sections/certifications.js` |
| GitHub page settings | `js/sections/github.js` |
| GitHub live loading | `js/github-feed.js` |
| Contact details and resume link | `js/sections/contact.js` |
| Resume | `resume/resume.html` (the PDF is made from it) |
| Order of the menu | `js/main.js` |
| Side menu and phone menu | `js/navigation.js` |
| Loading screen | `js/loader.js` and `css/loader.css` |
| 3D character | `js/avatar.js` |
| Changing role words | `js/roles.js` (the words are in `about.js`) |
| Live clock | `js/clock.js` |
| Project picture behaviour | `js/previews.js` |
| Device, white and dark mode switch and its circle effect | `js/theme.js` |
| Tour cursor | `js/tour.js` |
| Colours and fonts | `css/theme.css` |
| Top bar, side menu, footer styles | `css/layout.css` |
| Section styles | `css/sections.css` |
| Tour cursor styles | `css/tour.css` |

The tour cursor's message for each section is at the top of that section's file.
The messages for the side menu, the mode button and the goodbye are at the top of `js/tour.js`.
